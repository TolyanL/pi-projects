# M0 spike — результаты

Дата: 2026-02-14. Проверено на pi 1.5.0, Node 26, Linux.

Цель M0: доказать, что модель «проект = сессия» вообще работает, до написания
настоящего расширения. Все четыре риска закрыты.

| # | Гипотеза | Как проверяли | Результат |
|---|---|---|---|
| S1 | Пустой header-only `.jsonl` принимается pi, первое сообщение дописывается в него, сессия видна в `list`, после перезапуска cwd восстанавливается | `spike/harness.mjs` (SDK, offline) + `spike/tui_smoke.py` (реальный TUI в pty) | PASS |
| S2 | Левая панель как `nonCapturing` overlay реально рисуется, не ломает ввод, переживает resize | TUI в pty 120×40 → команды `/m0`, resize до 100×30, проверка вывода | PASS |

Дополнительно проверено:
- `SessionManager.list(project)` видит сессию, `list(hub)` — нет;
- `SessionManager.open(file)` после записи сохраняет `cwd` и историю;
- повторный запуск `pi --session <file>` восстанавливает и историю (`pong-1`), и
  cwd (в футере путь проекта);
- `/m0 open <path>` переключает прямо в живом TUI, панель переносит маркер `▸`
  на новый проект, агент продолжает отвечать;
- отрисовка панели даёт строки ровно заданной ширины на 24/30/40 колонках
  (`spike/render.mjs`).

## Находки, которые меняют дизайн

1. **Коллизия секций.** У pi есть **встроенная** секция `project_context`, куда
   попадают `AGENTS.md`/`CLAUDE.md` (видно в системном сообщении:
   `<project_context><project_instructions path=...>`). Наш план писать приватный
   контекст в `sections.project_context` **затёр бы AGENTS.md**.
   → ключ должен быть уникальным: `pi_projects_private`.
2. **`ctx.ui.notify` внутри `withSession` бесполезен.** pi после switch сам
   показывает статус `Resumed session` и затирает наше уведомление. → факт
   переключения показываем панелью/`setStatus`, а не notify.
3. **Overlay переживает resize**, но pty-тесту нужен явный `SIGWINCH` процессу:
   `TIOCSWINSZ` на master не доставляет сигнал, если pi — лидер сессии. На
   практике pi ресайзится штатно.
4. **Header-only сессия — валидный сценарий**, `_setSessionFile` ставит
   `flushed=true` и дальше пишет append'ом. Файл сортируется как обычная сессия
   (имя = ISO-время с `:`→`-`).
5. **Панель рисуется поверх транскрипта** — на 120 колонках правый бордер панели
   режет начало строк, как и ожидалось. Это цена API pi, не баг реализации.

## Как воспроизвести

Headless (без TUI, без сети, без модели):

```bash
cd pi-projects
node spike/harness.mjs
node spike/render.mjs
```

Реальный TUI (offline-провайдер `stub`, локальный SSE-сервер):

```bash
cd pi-projects
node spike/stub-server.mjs &          # слушает 127.0.0.1:8765
python3 spike/tui_smoke.py            # pty 120x40, команды /m0, resize, resume
```

Сырой поток терминала и логи: `spike/.tmp/tui.log`, `spike/.tmp/tui-resume.log`.

Руками (нужен живой терминал):

```bash
cd pi-projects
PI_M0_PROJECTS=/path/a:/path/b PI_M0_CONTEXT=/tmp/private.md \
  pi -e ./spike/m0.js
# /m0 list, /m0 open /path/b, /m0 panel, /m0 context
```

`node_modules/@earendil-works/*` — симлинки на глобальный pi (только для
локального harness/typecheck, в пакет не входят, см. `.gitignore`).
